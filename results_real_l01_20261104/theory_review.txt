C0=70、L0=1 理论独立审查（2026-11-04）

结论
这一参数组的估计器可以正确实现并进行实验。标量临界根、C0=70 的指数余量、全部 L>=1 的基本参数条件以及小 L 的下偏差界可以独立核验。现有旧证书还能覆盖 L>=14。但当前缺少新证明的完整文件和小 n 上偏差证书，不能将本次实验写成“已完整证明 C0=70、L0=1 对所有分布有 >2/3 成功率”，也不能将最小常数可取和完整必要性证明标记为已独立复核。

1. 已严格独立核验的标量结论
使用两套独立超越函数实现：仓库的整数/有理数向外舍入区间，以及 512-bit Arb。
  69.0062713812 < Cstar < 69.0062713813。
  H(alpha0(70)) = 0.492919920280915224476713804592... < 1/2。
  2H(alpha0(70))-1 = -0.0141601594381695510465723908157...。
H'(alpha)=asinh(alpha/32)>0，alpha0(C) 随 C 严格下降，结合端点极限确定唯一根。
Phi 的导数与驻点 t=sqrt(1024+alpha^2)-32、最大值 H 的代数相符。
这里认证的是临界方程及相关代数；要从系数渐近式推出全分布有限 n 成功率，还需要统一余项、上尾概率与所有尺度的控制。

2. 参数有效性与 b<=1 守卫
J=floor(log2(256 L^2/70)) 在 L>=1 非负，定义保证 0<A_j<=B/2。
因为 (j+3)2^(-j/2) 随 j>=0 下降，k_j<=alpha0(70)L+1；而 sqrt(B(B-A_j))>=64L/sqrt(2)，故要求的次数条件对所有 L>=1 成立。Chebyshev 的 cosh 恒等式还给出 rho_j<=delta_j^2/2。
额外逐点检查了 n=1,...,403 的所有尺度及取整，见 JSON。

原文 Lemma 2.3 的陈述含 b<=1，但 Appendix A 的证明并未使用它。具体地：
  (a) 0<=x<=a 用 P 的凹性和 P<=0；
  (b) a<=x<=b 用 |P|<=rho；
  (c) x>=b 令 u=2(x-b)/(b-a)，用 x>=sqrt(2b(b-a)u) 与 m sqrt(b(b-a))>=k，得到 exp(-mx)T_k(1+u)<=1。
三部分均不要求 b<=1。系数估计仅使用 a/b<=1/2，也与 b 的绝对大小无关。因此这一引理可以延拓到任意 0<a<b。
旧代码拒绝 b>1 是保守守卫。C=70 时，n=2,...,9 且 epsilon 较大可触发它（例如 n=3 时 epsilon>约0.745032）；移除这一守卫需要上述引理延拓，但不改变多尺度公式、次数取整或输出规则。这个延拓本身并不证明完整成功率。

3. 小 L 下偏差界已独立验证
若 Delta_r>=epsilon，则发现第 r+1 个不同类别之前，每次新样本成为新类别的概率至少为 epsilon。Poisson 化和适应性稀疏化给出
  Pr(D<=r)<=Pr(Poi(m epsilon)<=r)。
对 r<=n、C>=69、1<=L<=32，用 Chernoff 界
  Pr(Poi(Cn/L)<=n)<=exp{-n[C/L-1-log(C/L)]}
并把连续 L 区间分成 992 个闭区间，以 Arb 向外舍入计算。独立上界小于摘要声称的 2e-12，实际认证数值记录在 JSON 中。
该结果只处理下偏差，不能替代上偏差及联合成功率证明。

4. C=70 的充分性仍需区分已覆盖和未覆盖范围
用户摘要的完整充分性声明是 C in [Cstar,69.00628]；小参数证书声明仅对 C in [69.00627,69.00628] 一致成立。两个区间都不包含 70。
不能仅由“70 更大、样本更多”自动外推：A_j=C 2^j/(8L)、归一化系数和次数 ceil 都随 C 变化，J 也可能跳变，因此不同 C 的统计量没有已证明的逐样本或随机单调关系。B=64L 在缩放坐标中固定，而原概率坐标的 b=B/m 会改变。

仓库已有 C=70、L0=14 的证明和审查证书。对 L>=14，即 n>=ceil(exp(13))=442414，L0=1 与 L0=14 执行相同的多尺度估计器，可继承既有证书的联合失败概率上界 0.000879401164。这里引用并记录既有证据；本脚本没有重新运行旧证明的全部 32752 项检查。
因此本轮尚未补齐的是 n<442414 的新上偏差/联合保证。摘要声称 L>=32、69<=C<=70 的上界本身包括 70，但完整推导也未提供；现有 L>=14 证书已经覆盖更大的区间。

5. 式(8)同均值归约：仅有数值诊断，尚未独立证明
固定其它变量后，目标作为一个 lambda 的函数可写为
  A+exp(-lambda)[(y-1)A+lambda(B-A)]，B>=A>=0。
其有限最大点位于 lambda=1+(1-y)A/(B-A)>=1；退化情形的上确界可能在无穷远。这只解释了优化域为何可从 lambda>=1 开始，不能据此推出全部均值相同。
使用 r=2,3,4,5、随机非负非减 phi、固定随机种子 23 进行数值诊断；对齐单均值目标的多个局部峰，避免错误地假设它单峰。480 个测试中未发现有效反例。非凸数值搜索、有限测试和没有反例均不是式(8)的证明。

6. 暂不能认证的另外两项主张
“Cstar 本身可取”需要核查统一系数前因子 0.053、所有 L>=32 的上下尾组合，以及所有小 n/取整边界的证书；仅由 H=1/2 不能推出。
“每个 C<Cstar 必然失败”的轮廓与高方差三角阵列反例相容，但完整论证还依赖方差下界、中心化均值相对阈值的控制、Lindeberg 条件、奇数次数子列和全部 C 范围。摘要给出的式子不能替代这些推导的完整审查。
