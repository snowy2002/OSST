C0 与 L0 的联合优化：结论、证明结构与复现
2026-10-21

一、已经证明了什么

保留原论文的多项式、分层尺度、次数、权重、判定规则，只改变采样系数 C0 和分支阈值 L0。
定义 C* = 144 (ln 2)^2 = 69.185234004221...。

可证明的参数组合与统一失败率上界（向上取整）：
  C0 = C*，L0 = 16：失败率 < 0.317480，成功率 > 2/3。
  C0 = 70，L0 = 16：失败率 < 0.282612，成功率 > 2/3。
  C0 = C*，L0 = 15：失败率 < 0.392089，成功率 > 3/5。
  C0 = 70，L0 = 20：失败率 < 0.072224，成功率至少 0.92。

这些界同时适用于：
  1. 支持大小 S <= n 时，二元判定的错误概率；
  2. 去掉前 n 个最大概率后剩余质量 >= epsilon 时，二元判定的错误概率；
  3. 对任意分布，输出的整数下界满足
       min(eff_epsilon(p), n) <= S_hat <= S
     这一联合事件的失败概率。
前三项是分别成立的概率保证；若要求二元判定和下界输出同时正确，可再作一次并集界。
覆盖有限或可数支持的所有离散分布、所有正整数 n、所有 0 < epsilon < 1。
epsilon 是问题的分离参数，不是失败率。

这不是全局最优性结论。目前没有证明所有 C0 < C* 的参数都不可行，
也没有证明所有 L0 < 16 的参数都不能达到 2/3。
旧结论中的 1025 固定了 L0 = 1024 和 1% 的错误目标；本次改变了这些条件。

二、算法与样本模型

L = 1 + ln n，m = C0 n / (epsilon L)。
先取 M ~ Poisson(m)，再取得 M 个独立同分布样本。
各类别计数 N_i 因而独立，N_i ~ Poisson(m p_i)。

L < L0 时只数观察到的不同类别 D；否则使用原来的 Chebyshev 多项式估计量。
完整公式见 joint_constants.pdf 第 1 节，未省略次数的向上取整和尺度的向下取整。
Poisson 的均值可以是实数，定理不要求把 m 取整。

三、为什么能把 C0 降低这么多

关键不是把旧证明中的 1025 直接替换成 70，而是重做权重和方差估计。

第一步：控制均值。
每个尺度 j 都满足
  (1-rho_j) sum_i min(p_i/a_j, 1) <= E Z_j <= (1+rho_j) S，
  rho_j <= delta_j^2 / 2。
完整证明分别处理 x 位于 [0,a]、[a,b]、[b,+infinity) 的情况。

第二步：改进权重上界。
把权重的绝对系数写成 u_l = |c_l| l! / m^l。
利用 Chebyshev 多项式的显式系数，可以逐个证明
  u_l <= rho (4t)^l l!/(2l)! exp(2w/(2l+1))，
其中 t = k^2/[m(b-a)]，w = k^2 a/(b-a)。
再证明 (4t)^l l!/(2l)! <= exp(t)。
将 l <= 7 和 l >= 8 分开，就不会额外损失一个随 L 增长的因子。
这里的系数恒等式和不等式已用独立的有理数多项式递推交叉验证。

第三步：利用更准确的方差界。
设 I = sum_l u_l，可以证明 f 的整个取值范围长度不超过 I。
所以对于有限支持 S，有 Var(Z_j) <= S I_j^2/4。
对于一般分布，则有 Var(Z_j) <= ||f_j||_infinity^2 E D。
这两种界适用条件不同，不能混用。

第四步：改用单侧浓缩，而非统一的双侧大偏差事件。
使用 Cantelli 不等式：
  P(X-E X >= t) <= Var(X)/(Var(X)+t^2)。
零假设的多个尺度需要并集界；拒绝分布只需找到一个有足够均值间隔的尺度。
对不同分布的三个互斥情形，取最大错误界，不把三种情形的错误率相加。
证明分别处理：p_(r) >= b/2、p_(r) < a0、a0 <= p_(r) < b/2。

第五步：单独证明下界输出的联合正确性。
S >= n 时，输出已截断到 n，上侧约束自动满足。
S < n 时，用有限支持的方差界同时控制上侧和下侧错误。
因此没有把“二元判定正确率 >= 2/3”误当成“下界联合正确率 >= 2/3”。

四、C* = 144 (ln 2)^2 从哪里来

最困难的第 0 个尺度的主导参数为
  t0 = 72 (ln 2)^2 / C0。
方差相对 n 的上界含有 exp((2t0 - 1)L)。
要让这条充分界在 L 趋于无穷时保持受控，可以取
  2t0 <= 1，即 C0 >= 144 (ln 2)^2。
在等号处，改进后的逐项系数界仍然给出足够小的常数错误界。
代码对 C0 = C* 的等号作符号消去，并未用浮点数猜测 2t0 是否小于 1。

这个数是本证明给出的充分常数，不是算法必须满足的下界。
如果进一步改进系数界或利用分布结构来控制方差，仍可能下降。

五、为什么代码不是只检查了几个 n

L < L0 的计数分支：使用发现时间的随机支配和 Poisson Chernoff 界，解析覆盖所有 n。
15 <= L <= 32：划分为 170 个完整闭区间，每段宽度 0.1。
对每一整段推导保守包络，覆盖区间中的所有实数 L，以及次数和尺度跳变。
两个 C0 一共 340 个区间，使用 Arb 的 256 位外向舍入区间运算。
L >= 32：解析证明各项包络单调不增，只需要认证端点及导数符号。
可数无限支持：以尾部质量趋零的 L2 收敛来证明截断极限合法。

因此不是对有限 n 网格做模拟以后宣称覆盖无穷范围。
另一方面，这也不是 Lean/Coq 等证明内核中的形式化验证。

六、多次运行如何放大

需要固定的统一优势 q >= 1/2 + gamma，gamma > 0 不依赖分布、n 或 epsilon。
二元判定用多数投票；下界整数输出用中位数。
每次必须取得独立的新样本和独立的 Poisson 样本数。

奇数次 r 重复后，任一任务的错误率至多
  sum_{k=(r+1)/2}^r binom(r,k) (1-q)^k q^(r-k)
  <= [4q(1-q)]^(r/2)
  <= exp(-2r(q-1/2)^2)。

当超过一半的下界输出落在同一个有效区间内，中位数也必在区间内。
这是中位数放大的依据，不需要估计量无偏。
复用同一份数据只换随机种子，或普通 bootstrap，不自动满足独立新样本的前提。

精确二项式计算的例子：
  只使用 q >= 2/3：47 次足以使错误率 < 1%。
  只使用 q >= 3/5：133 次足以使错误率 < 1%。
  使用 (C0,L0)=(70,20) 的 q >= 0.92：5 次的错误率 <= 0.0045252608。

最后一种方案的总期望样本数是
  350 n / (epsilon (1+ln n))。
若要求二元输出和下界输出同时正确，5 次方案的并集错误率 <= 0.0090505216，仍低于 1%。
如果只依赖 2/3 的粗保证，70*47=3290，反而超过此前的 1025。
所以应比较总样本系数，不应只看单次 C0。
