                                  Optimal Support Size Testing

                                                    Qisheng Wang  ∗




                                                         Abstract
           We present an optimal tester for support size that determines whether an unknown prob-
       ability distribution is supported on n elements or ε-far away (in total variation distance) with
       sample complexity Θ(     nε log(n)),  improving the prior best O(     nε log(n) log(min{ 1ε, n})) due toFer-
       reira Pinto Jr. and Harms (STOC 2025).  As a generalization, we provide a            pretty  good lower
       bound on support size.

1   Introduction

The support size of an unknown discrete probability distribution is an important measure of species
diversity in ecology [FCW43]. The estimation of support size has been subsequently investigated
in statistics from a theoretical perspective [Goo49,Goo53] (cf. [BF93]). Since “I don’t believe it is
usually possible to estimate the number of unseen species [i.e., support size]” (quoting I. J. Good
in [BF93]), the best we can hope is to consider weaker tasks with promise rather than estimation
in all cases. Among them, support size testing is a basic statistical decision problem in property
testing (cf. [Gol17, Section 11.4]).

Problem  1 (Support size testing). Given an unknown probability distribution  p, the task is to
determine whether p is supported on at most n elements or ε-far in total variation distance from
any distribution supported on at most n elements. Formally, determine whether

                                  Yes: |supp(p)| ≤ n    or    No:  ∆n(p) ≥ ε,

with the promise that it is in either case. Here, supp(p) = {i: pi > 0} denotes the set of elements
with nonzero probability, and ∆n(p) = infq : |supp(q)|≤n dTV(p, q) denotes the total variation distanceP
of p to distributions supported on at most n elements, where dTV(p, q) =  12                      i|pi − qi|.

    This problem has been investigated in a series of works [GR22,AF24,AFL24,KLR25,FH25].
In particular, the prior best approach is with sample complexity O(     nε log(n) log(min{1ε, n})) due to
[FH25], improving the prior approaches via learning histograms [VV11,VV17,HJW18,HO19] with
sample complexity O(      nε2 log(n)). However, the prior best lower bound is Ω(     nε log(n)) implied by [VV11,
Theorem 2] and [WY19, Proposition 1]. There still remains a gap of            log(min{1ε, n}) between the
upper and lower bounds. In this paper, we present an optimal support size tester, thereby closing
this gap.

Theorem 1.1 (Optimal support size testing). There is an algorithm for support size testing with
optimal sample complexity Θ(     nε log(n)).

1.1    Generalization:  Pretty good lower bound on support size
As a generalization of this result, we can further give a pretty good lower bound on the support
size, without any assumptions on the distribution.

Theorem 1.2 (Prettygoodlowerboundonsupportsize). There is an algorithm that uses Θ(     nε log(n))
samples drawn from an unknown distribution p and outputs a number bS ∈ {1, 2, . . . , n} such that
with probability at least 2/3,
                                         min{effε(p), n} ≤ bS ≤ |supp(p)|,                           (1)
where effε(p) is the ε-effective support size of p,1 the smallest number k ∈ N such that there is a
distribution q with |supp(q)| = k and dTV(p, q) ≤ ε.

    If an estimate bS satisfies Equation (1), then we call it a  pretty good lower bound on support size,
which is a stronger definition than the good lower bound on support size  min{effε(p), n} ≤ bS ≤
(1 + ε)|supp(p)| defined in [FH25, Corollary 1.6], where we remove the factor           (1 + ε). Theorem1.2
can also be interpreted as: using m samples, one can obtain a lower bound on support size at least
min{effε(p), Θ(εm log(e+εm))}, which improves the lower bound min{effε(p), Θ(      εlog(1/ε)m log(m))}
in [FH25].
    The algorithm in Theorem1.2is also optimal since a pretty good lower bound on support size
can solve the support size testing problem:  |supp(p)| ≤ ⌊n/2⌋ vs ∆⌊n/2⌋(p) ≥ 2ε,2 and thus the
lower bound Ω(     nε log(n)) for support size testing [VV11,WY19] applies.

1.2    Implications in distribution-free sample-based testing
In [FH25], they provided an algorithm for testing the class         Hn of Boolean functions f : N → {0, 1}
with |f−1(1)| ≤ n with sample complexity O(n log(1/ε)ε log(n)  ) in the distribution-free sample-based test-
ing model [GR16,Gol17,RR20,BFH21,RR22].  Testing Boolean function classes can aid the
proper PAC (probably approximately correct) learning in model selection when testing is faster
than learning.  As an implication of our results, combining [FH25, Theorem 1.8], we settle the
sample complexity of testing Hn.

Theorem 1.3 (Optimal distribution-free sample-based testing for Hn). There is an algorithm that
uses Θ(     nε log(n)) samples of the form (x, f(x)) with x ∼ p for an unknown function f : N → {0, 1}
and an unknown probability distribution p, and determines whether f ∈ Hn or f is ε-far from Hn
(i.e., infg∈Hn Prx∼p[f(x) ̸= g(x)] ≥ ε) with success probability at least 2/3.

Proof. [FH25, Theorem 1.8] gives          mHn(n, ε) ≤ msupp(n, ε) + O(1/ε) where mHn(n, ε) is the sample
complexity of testing Hn and msupp(n, ε) is the sample complexity of support size testing.

    The upper bound in Theorem1.3matches the lower bound                    Ω(     VCε log(VC)) due to [BFH21] (cf.
[FH25, Section 1.3]), where the VC (Vapnik–Chervonenkis) dimension of         Hn is VC(Hn) = n.

New strategy for testing.  Rather than directly focusing on support size testing, we aim to deal
with giving a pretty good lower bound on support size as well. Namely, our goal is to directly find
a pretty good lower bound bS on support size such that min{effε(p), n} ≤ bS ≤ |supp(p)|. If this can
be done, it already gives a support size tester, as explained in Section1.1. So, in the following, we
skip directly to solving this harder task and we will explain why the harder task will give hints to
an optimal support size tester.

Step 1:  Removing the multiplicative factor (1 + ε).  The reason that the good lower bound
on support size obtained in [FH25] has an upper bound of           (1 + ε)|supp(p)| with a multiplicative
factor (1 + ε) is that if |supp(p)| ≤ n, the best possible upper bound on E[bSFH] we can have is
already E[bSFH] ≤ (1 + δ)|supp(p)| where δ  = ε/4 (see [FH25, Lemma 3.7]). On the other hand,
|bSFH − E[bSFH]| ≤ δn with high probability (see [FH25, Lemma 3.17]). The two inequalities inspire
us to consider the case where there is a tester bS such that with high probability,

1.4    Independent and Simultaneous Work
During the preparation of this paper, the author became aware of the independent work [BGY26]
with an optimal support size tester over a finite alphabet.  Although both approaches employ
polynomial estimators, their algorithmic construction is substantially different. Specifically, they
first amplify the samples by taking unions, construct an initial set of observed elements, and then
reduce the problem to testing bounded residual sets, involving the Fejér polynomial. In contrast,
our approach directly deals with the empirical counts using sub-testers involving affined Chebyshev
polynomials. Furthermore, ourapproachyieldsaprettygoodlowerboundonsupportsize, providing
a numerical guarantee beyond support size testing.
