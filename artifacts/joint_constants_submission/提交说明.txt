核心定理

令 C* = 144 (ln 2)^2 = 69.185234004221...。
保持原论文估计量、尺度、次数、修正项和判定规则，只改变 C0、L0。

1. (C0,L0) = (C*,16)：每个规定任务的失败率 < 0.317480，因而成功率 > 2/3。
2. (C0,L0) = (70,16)：失败率 < 0.282612。
3. (C0,L0) = (C*,15)：失败率 < 0.392089，成功率 > 3/5。
4. (C0,L0) = (70,20)：失败率 < 0.072224，成功率至少 0.92。

“规定任务”包括：两个承诺类上的二元判定，以及对任意分布的支持大小下界联合有效性。
这里 epsilon 是总变差距离的分离参数，不是失败率。
所有上界都是严格有理数比较得到的充分上界；没有声称 C* 或 L0=16 全局最小。

一、数字认证现在完全使用整数和有理数。
   不依赖 Arb、NumPy、SciPy、mpmath 或浮点超越函数库。
   log(2)、pi、exp、sqrt 的包络都有附录中的数学证明。
   每个有理数上下端点由整数向下/向上取整构造。
   340 个完整区间及 L >= 32 的解析半直线覆盖全部参数范围。

二、补齐容易被审稿人追问的逻辑环节。
   总变差距离与尾部质量等价；无穷支持下的绝对可积和 L2 截断；
   Chebyshev 系数递推；取值范围方差界；单侧尾界；均值间隔；
   n=1、阈值等号、ceil/floor 跳变及下界输出的整数截断。
   二元判定在承诺间隙中没有规定正确标签，但下界联合保证仍然适用。

三、补齐放大与确定样本预算。
   独立新样本下，二元输出取多数票，下界输出取中位数。
   成功率至少 q > 1/2 时，r 次奇数重复的失败率至多
      sum_{k=(r+1)/2}^r binom(r,k) (1-q)^k q^(r-k)
      <= exp(-2r(q-1/2)^2)。
   抽取 Poisson 样本数后，若超过 ceil(2m) 就直接返回固定输出，可得确定的样本上限。
   该封顶额外错误率小于 10^(-9)，表中方便使用的成功率保证均保持成立。
   (70,20) 封顶算法独立运行 5 次：
      单个任务失败率 <= 0.0045252608；
      两个输出中任一出错的概率 <= 0.0090505216；
      总期望样本数 <= 350 n/[epsilon (1+ln n)]；
      总样本数始终 <= 700 n/[epsilon (1+ln n)] + 5。
