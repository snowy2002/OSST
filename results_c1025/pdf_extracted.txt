Evaluating an Explicit Constant for Support-Size Testing
Reproducible experiments for C0 = 1025, with proof appendix
Abstract
We evaluate the explicit coeﬃcient C0 = 1025 for Wang's support-size tester, conditional on the accom-
panying proof and with L0 = 1024 unchanged. The frozen main design comprises 9,130,000 independent
simulated Poisson-process paths and 39,720,000 paired method evaluations. Synthetic sizes range from 1
to 1012 across ﬁve separation parameters and up to ﬁfteen distribution scenarios. Ten published empirical
populations cover trees, mites, birds, spiders, moths, snails, and ﬁsh. No errors are observed for C0 = 1025 in
the promised primary cells; worst simultaneous 95% error upper bounds are 0.107% on synthetic and 0.095%
on empirical populations. However, all practical sizes use the observed-count branch, a simple certiﬁed count
baseline requires fewer samples, and only 2 of 236 ecological conﬁgurations have as many original records as
the prescribed mean. Correlation stress tests expose violations of the iid requirement. Full-degree interval
checks and public-API executions support implementation ﬁdelity without substituting for a universal proof
or a ﬁeld validation.
1
Question and claim boundaries
We test the proposed constant reduction from 226 to 1025 in the supplied manuscript [1]. For integer n ≥1,
separation 0 < ϵ < 1, and L = 1 + log n, the prescribed Poisson mean is m = ⌈C0n/(ϵL)⌉. The separation
parameter ϵ is not the target error probability, which is 0.01. Yes instances satisfy S ≤n; No instances satisfy
∆n(p) ≥ϵ.
Gap instances satisfy neither promise and receive no classiﬁcation-error label.
We also check
min{eﬀϵ(p), n} ≤bS ≤S for every distribution, including Gap instances.
The coeﬃcient reduction is an analytic reﬁnement of the same construction, not a new asymptotic sample-
complexity rate. Empirical evidence addresses ﬁnite tested distributions. It cannot establish uniform correctness
over all distributions or integer minimality. In particular, C0 = 1024 also succeeds on the tested practical grid;
its theoretical obstruction lies near n = e1023 ≈10444.28. The accompanying proof is included in the appendix
for a precise statement of scope.
2
Implementation and comparators
The public reference interface now accepts an explicit sampling coeﬃcient and records it in every output, while
retaining the original coeﬃcient as its default. Parameters, branch decisions, integer rounding and outputs are
computed with Arb intervals and adaptive precision. The command python paper_reference.py demo –n
1000 –epsilon 0.1 –c0 1025 runs the new coeﬃcient. All tested practical n satisfy L < 1024, so the literal
algorithm is D > n for rejection and bS = min{max{D, 1}, n}. We do not force a polynomial branch at small n
or attribute tuned practical variants to this theorem.
Comparators are the original C0 = 226 construction, C0 = 1024 as a coeﬃcient control, and a count baseline
with the same 1% target. For the latter, let a = log 100 and choose mcount = ⌈(n+a+
√

is a conservative analytic count baseline, not a data-tuned oracle. Constant sweeps below 1025 are sensitivity
experiments without a claimed universal theorem.
3
Experimental protocol and statistical analysis
The primary grid uses n ∈{1, 2, 10, 102, 103, 104, 106, 109, 1012} and ϵ ∈{0.001, 0.01, 0.05, 0.1, 0.25}. Scenarios
include uniform and smaller-support nulls, dominant heads with extremely rare tails, piecewise power-law,
lognormal, discrete Gaussian-shaped and geometric-shaped nulls, near-boundary uniform alternatives, diﬀuse
and ultradiﬀuse tails, multiscale alternatives, clear alternatives, and two Gap controls. Blocked shapes are
explicitly constructed discrete distributions, not claimed exact continuous Gaussian or lognormal laws. Invalid
null variants at n = 1 are omitted prospectively. Promise labels and eﬀective-support integers are checked with
rational arithmetic; empirical-data labels are additionally checked from integer counts.

Poisson-process occupancies within a trial for paired comparisons. For a group of g equal-probability categories,

Risk and acquisition-budget results
The main experiment comprises 645 synthetic cells and 236 empirical cells, each evaluated by four methods.
The C1025 joint lower-bound failure upper limits are 0.108% and 0.098%, respectively, below the theorem's
2% joint target. The count baseline also meets the 1% error target on the tested grid. Thus the experiments
support implementation correctness and conservative guarantees, not practical sample-eﬃciency dominance.
Across the synthetic grid, the C1025 budget is 35.8–135.2 times the count-baseline budget. Reducing the
original coeﬃcient changes its prescribed mean by approximately 65,472 times; this does not imply an equal
wall-clock speedup or equal savings relative to a stronger ﬁnite-scale baseline. The coeﬃcient sweep ﬁnds much
smaller suﬃcient tested constants on its restricted scenarios. Such selected grid values are not universal optima.

6
What can the original ecological records validate?
Only 2/236 ecological conﬁgurations have N ≥m1025. We also report Pr{Poi(m) > N}, because N ≥m alone
does not guarantee a feasible Poisson draw. The only mean-feasible conﬁgurations are from the mite dataset.
We run 200 ﬁnite-ﬁle Poisson subsampling attempts for each and retain every overﬂow rather than redrawing.
These without-replacement ﬁle analyses are descriptive: the underlying spatial core collection has not been
established to be an iid sample from the desired external population. For insuﬃcient ﬁles, resampling with
replacement does not create additional independent ecological evidence.
In the mite conﬁgurations, (n, ϵ, m, N) = (6, 0.25, 8812, 9800) and (7, 0.25, 9743, 9800).
The ﬁrst has no
overﬂows in 200 attempts; the second has 52 in 200, consistent with its nominal overﬂow probability of about
0.280. Both thresholds already lie below the 35 observed species, so these runs do not establish previously
unknown ecological richness or certiﬁed acceptance.
Observing more than n valid species directly refutes S ≤n without an iid assumption. Conversely, seeing
at most n species in an inadequate or biased survey does not certify acceptance. In particular, neither a high
empirical resampling success rate nor an algorithmic Yes proves a complete species inventory. Sampling eﬀort,
detection bias, spatial clustering and the chosen biological sampling unit must be speciﬁed for a ﬁeld application.
7
Dependence, held-out groups and stopping rules
We test two controlled departures from independence while retaining the same marginal species distribution:
identical-label duplication and multiple labels drawn within real abundance-weighted groups.
Their worst
observed false-negative rates are 99.825% and 42.400%, respectively. These deliberate stresses are not estimates
of natural ﬁeld dependence. Selecting a group independently for every individual with probability proportional
to its abundance recovers the pooled empirical iid target; batching individuals within the same selected group
does not.
Five 70/30 group splits per grouped dataset select n using training groups only. Held-out ﬁnite populations
are independently resampled and scored using their own truth. No errors are observed on promised held-out
cells; 5 cells are Gap instances and are not silently assigned a failure label. This measures robustness to ﬁnite
empirical heterogeneity, not unknown species outside both splits.

Reproducibility and limitations
The artifact contains prospective design ﬁles, all primary trial occupancies, per-seed results, exact target audits,
source snapshots, environment versions, source-data provenance, ﬁgures, code and LaTeX. Run python -m
c1025.run –phase all, then python -m c1025.supplement, python -m c1025.numeric_extra, and python
-m c1025.report.
Existing completed stages are preserved.
The new raw-output audit recomputes every
primary decision, conﬁdence bound and lower-bound failure from saved trials. A local frozen protocol is not an
external preregistration.
The tested biological collections are diverse but small, historical, and nonrandomly selected; their reference
supports omit undiscovered species. No new ﬁeld survey or external full-population inventory was obtained.
The practical grid cannot distinguish 1024 from 1025 at the astronomical worst-case boundary. The proof is
not certiﬁed by a proof-assistant kernel or independent peer review. The evidence supports a precise constant-
reﬁnement evaluation with explicit negative results; publication novelty and ﬁt to a speciﬁc conference remain
separate questions. No conference template or acceptance claim is implied.
